# HITL Annotation Tool (NER + RE)

## Overview
This project implements a Human-in-the-Loop (HITL) annotation system for Named Entity Recognition (NER) and Relation Extraction (RE) using Large Language Models.  
Domain experts can review, edit, accept, or reject model predictions and provide justifications.

---

## Features
- Full article view for context understanding  
- Highlighted text showing extracted named entities  
- NER annotation review (accept/reject, edit label, add justification)  
- Relation Extraction review (accept/reject, add justification)  
- Ability to add missing entities and relations  
- Save corrected annotations for evaluation and analysis  

---

## Purpose
This system is designed to support model evaluation and improve annotation quality through domain expert feedback in NER and RE tasks.
